# SIMADA – Sistem Informasi Manajemen Pengadaan
OOP PHP 8 + MySQL. Kelompok Larissa, Niki, Novi.

1. Salin folder `simada` ke `C:\xampp\htdocs\`, jalankan Apache & MySQL.
2. phpMyAdmin → Import → `database/simada.sql`.
3. Buka http://localhost/simada/public/
